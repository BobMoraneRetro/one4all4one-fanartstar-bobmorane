"RFE Retrofist Nostalgia" view: supplied backgrounds
===================================================

Each background <name>.png comes with <name>.xml (its settings). Available settings: see README.txt.

Default backgrounds
  _default.png   : default background for 4:3 systems (if the system has none)
  _default16.png : default background for 16:9 systems (ps3, ps4, xbox360, wiiu, switch, psvita, windows, steam)
  arcade.png     : default background for arcade systems (all those of type arcade in es_systems: mame, fbneo, naomi...)
  arcade.xml     : settings of arcade.png (instead of _default.xml for these systems)
  computers.png  : default background for computer systems (type computer in es_systems: amiga, c64, amstradcpc...)
  extension.png  : default background for console add-ons (type extension in es_systems: megacd, sega32x, fds, satellaview, sufami, n64dd, sgb, *-msu...)
  pinball.png    : default background for pinball (type pinball in es_systems: vpinball, fpinball, pinballfx...)
  port.png       : default background for ports (type port in es_systems: doom, quake, scummvm, soh, sonic-mania...)
  portable.png   : default background for handhelds (type portable in es_systems: gb, gbc, gamegear, nds, psp...)
  auto-collection.png : default background for automatic collections (all games, favourites, last played, genres...)
  custom-collection.png : default background for custom collections (created by the user)
  retrobat.png   : background of the RetroBat system and default background for systems without a type (kodi)

Variants (external _bobmedia folder only): the *_alt.png files (3ds_alt, gbc_alt) and Dragonball.png are spare
versions, never read automatically: rename to <system>.png to use them.

Automatic collections: theme name auto-<name> (auto-favorites, auto-lastplayed, auto-allgames, auto-lightgun, auto-wheel...)
Custom collections: the file has the exact name of the collection (spaces included), list of recognised names: collections.info (theme root)
