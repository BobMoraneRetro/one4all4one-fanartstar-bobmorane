Visão « RFE Retrofist Nostalgia » : cenários fornecidos
=======================================================

Cada cenário <nome>.png vem com <nome>.xml (seus ajustes). Ajustes possíveis : ver LEIAME.txt.

Cenários padrão
  _default.png   : cenário padrão dos sistemas 4:3 (se o sistema não tiver o seu)
  _default16.png : cenário padrão dos sistemas 16:9 (ps3, ps4, xbox360, wiiu, switch, psvita, windows, steam)
  arcade.png     : cenário padrão dos sistemas arcade (todos os de tipo arcade no es_systems : mame, fbneo, naomi...)
  arcade.xml     : ajustes de arcade.png (no lugar de _default.xml para esses sistemas)
  computers.png  : cenário padrão dos computadores (tipo computer no es_systems : amiga, c64, amstradcpc...)
  extension.png  : cenário padrão das extensões de console (tipo extension no es_systems : megacd, sega32x, fds, satellaview, sufami, n64dd, sgb, *-msu...)
  pinball.png    : cenário padrão dos pinballs (tipo pinball no es_systems : vpinball, fpinball, pinballfx...)
  port.png       : cenário padrão dos ports (tipo port no es_systems : doom, quake, scummvm, soh, sonic-mania...)
  portable.png   : cenário padrão dos portáteis (tipo portable no es_systems : gb, gbc, gamegear, nds, psp...)
  auto-collection.png : cenário padrão das coleções automáticas (todos os jogos, favoritos, últimos jogados, gêneros...)
  custom-collection.png : cenário padrão das coleções pessoais (criadas pelo usuário)
  retrobat.png   : cenário do sistema RetroBat e cenário padrão dos sistemas sem tipo (kodi)

Variantes (só na pasta externa _bobmedia) : os arquivos *_alt.png (3ds_alt, gbc_alt) e Dragonball.png são
versões de reserva, nunca lidas automaticamente : renomeie para <sistema>.png para usá-las.

Coleções automáticas : nome de tema auto-<nome> (auto-favorites, auto-lastplayed, auto-allgames, auto-lightgun, auto-wheel...)
Coleções pessoais : o arquivo tem o nome exato da coleção (espaços incluídos), lista dos nomes reconhecidos : collections.info (raiz do tema)
